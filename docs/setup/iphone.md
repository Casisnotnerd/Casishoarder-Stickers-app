# Install on your iPhone

1. Open `https://<your-username>.github.io/sticker-vault/` in **Safari**.
2. Tap the **Share** button -> **Add to Home Screen** -> **Add**.
3. Open **Sticker Vault** from your home screen -> enter your email -> type the 6-digit code from the email.
4. To add sheets: Add -> Add a sheet -> choose **Take Photo** or **Photo Library** (works for shop screenshots too).
